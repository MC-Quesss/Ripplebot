# Storytelling Nights

A pre-bedtime tradition where Private asks Roz to tell a story, and all bots stay awake to listen.

## Flow

1. **Sunset** (timeOfDay 11300–12400): Private (PERSONA=private) has a 25% chance each night of calling everyone inside, then (after a ~60s gather wait) asking "Roz, would you tell us a story tonight? Please?" — the ask deliberately lands near bedtime (12500) so the tale carries into the night.
2. **Roz hears the request** via the existing `tell_story` LLM intent (accepted from timeOfDay 10300 up to 15000 — the late bound covers asks that land after bedtime).
3. **Roz announces** "Gather round, everyone." — this is the coordination marker. Bots already in bed wake for it.
4. **All bots** detect the marker in chat and suppress auto-sleep (`storyTimeActive = true`).
5. **Roz tells the story** — 7 lines (one per arc beat), ~4–6s between each, generated by the LLM.
6. **Roz ends** with "...That is my story." — the end marker.
7. **Auto-sleep restored** 5s after the end marker (all bots) — it is already night, so everyone drops straight into bed.

## Safety

- 2-minute timeout clears `storyTimeActive` if a story gets stuck.
- Story doesn't register as a task, so it doesn't block other operations.
- Only Private's persona triggers the request — other bots just listen.

## Coordination Protocol

Chat-based, same model as fire-duty roll call:
- Start: `"Gather round, everyone."` (exact match)
- End: `/that is my story/i` (regex match)

## Update — 2026-08-01: mythic tale engine (arcs × casts × settings)

Stories had collapsed into disconnected vivid lines — no arc, no character change.
Rebuilt as **4 story arcs × 4 cast sets × 4 setting sets** (Quesss's mad-lib design
from 2026-07-11, now implemented), modeled on the shapes of classic fireside folk
tales — the sun-hero quest with trials, the trickster who frees a hoarded gift, the
pourquoi/origin tale, the stranger who earns a place by the fire. Structures only,
no copyrighted text.

- `STORY_ARCS` in bot.js: each arc is a 7-beat sheet; the LLM writes exactly one
  line per beat, so every telling has a beginning, a turn, and an ending that lands.
- `STORY_CASTS` / `STORY_SETTINGS`: internally-cohesive swappable sets; any set fits
  any arc. Settings mythologize the bots' own world (the frozen [[../places/igloo]]
  lake, the wheat fields, the flock) so tales read as legends of the land.
- `composeStoryBrief()` picks arc (never the same arc twice in a row) + cast +
  setting; a player-given topic is woven in as hero/missing thing/gift, and topics
  about the bot itself still pull the persona backstory.
- `buildStorySystem` (llm.js, shared with claude.js) now demands ONE continuous
  story following the numbered beats; `cleanStoryLines` strips any `Line N:` labels.
- Stories are now 7 lines (was 5); `STORY_TIMEOUT_MS` raised 120s → 180s to cover
  generation + pacing. Coordination markers unchanged. Not protocol-breaking; each
  bot picks it up on its next restart.
- **Same day, timing shift (Quesss):** stories should carry INTO the night rather
  than finish early with awkward waiting before sleep unlocks. Request window
  moved from 9500–10500 to **11300–12400** (sunset); `tell_story` acceptance gate
  widened to 10300–**15000** so an ask landing after bedtime isn't silently
  dropped, which would strand a gathered crew with no story.
