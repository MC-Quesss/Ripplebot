# Smiley Cloud (Actually Additions)

A decorative block. Right-click opens a GUI to name it; the tile entity stores only that name and syncs it. The block puffs a few particles now and then. Nothing in the block, tile or easter-egg code spawns an item, so **no name makes a cloud give gifts**.

## Special names (easter eggs)

`SmileyCloudEasterEggs` holds about 35 eggs, each with one or more trigger names (over a hundred names in all), e.g. etho/ethoslab, direwolf20/dw20, xisuma/xisumavoid, vazkii, ellpeck, cloudhunter/cloudy, biffa. Each egg has a single method, `renderExtra`: a client-side drawing on the cloud. They are cosmetic only.

- **Etho / EthosLab:** draws redstone dust and a redstone block on the cloud.
